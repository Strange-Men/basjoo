# Reports

This directory contains evaluation reports generated by the RAG evaluation harness.

## Files

| File | Format | Description |
|---|---|---|
| `rag_eval_report.json` | JSON | Mock mode evaluation results |
| `rag_eval_report.md` | Markdown | Mock mode human-readable report |
| `rag_eval_real_report.json` | JSON | Real mode evaluation results (v2.0) |
| `rag_eval_real_report.md` | Markdown | Real mode human-readable report (v2.0) |
| `rag_eval_mock_vs_real.md` | Markdown | Mock vs Real comparison report (v2.0) |

## How to Generate

```powershell
cd backend

# Mock mode (no API key needed)
.\venv\Scripts\python.exe scripts\run_rag_eval.py --mock

# Real mode (requires SiliconFlow API key + Qdrant)
.\venv\Scripts\python.exe scripts\run_rag_eval.py --real
```
