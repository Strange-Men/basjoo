# Reports

This directory contains evaluation reports generated by the RAG evaluation harness.

## Files

| File | Format | Description |
|---|---|---|
| `rag_eval_report.json` | JSON | Machine-readable evaluation results |
| `rag_eval_report.md` | Markdown | Human-readable evaluation report |

## How to Generate

```powershell
cd backend

# Generate reports in mock mode (no API key needed)
.\venv\Scripts\python.exe scripts\run_rag_eval.py --mock
```

The runner will:
1. Load 15 eval cases from `tests/rag_eval/fixtures/rag_eval_cases.json`
2. Run each case through the mock RAG pipeline
3. Compute metrics (precision, recall, MRR, no-answer accuracy, citation accuracy)
4. Generate reports in this directory

## How to Interpret

### JSON Report

The JSON report contains:
- `generated_at`: Timestamp of report generation
- `test_mode`: "mock" (no real API) or "real" (with API keys)
- `summary`: Total cases, passed, failed
- `metrics`: All computed metrics

### Markdown Report

The Markdown report includes:
- Executive summary
- Metrics tables
- Per-case results
- Limitations and next steps
